Buenas tardes, hoy les presentamos nuestro proyecto de "Mi empresa". 
Este proyecto se ha de tratar sobre una tienda online de comics, mangas y libros de mayoria de fantasia.
hemos utilizado para la creacion de nuestro proyecto el programa Visual Studio code, para darle forma sacamos los codigos de la pagina de Boobstrap, dandole los diseños, los estilos y componententes. Cada codigo fue distribuido por las partes de las paginas, el inicio (osea el index), los integrantes y los productos mostrados de la misma; Mencionando a los integrantes, cada uno tuvo su papel distintivo en la creacion del proyecto. Uno tuvo la tarea de realizar la estructura de los codigos, otro tuvo que diseñar las paginas mostradas, y ya el ultimo ayudo al diseñador para guarlo con los mismos diseños de la pagina. 

Este proyecto fue llevado acabo por los siguientes integrantes:

1_ Antonela Espinoza: Diseñadora de la estetica y experiencia, encargada de todo lo posible tanto de la pagina como de la imagen publica demostrada en todo el diseño exterior.

2_ Benicio Pizarro: Encargado de implementacion de la estructura del sitio web y la funcionalidad del mismo. Implementando HTML, CSS y JavaScript para crear una experiencia de usuario fluida y atractiva.

3_ Ignacio Morales: Encargado de la Cordinacion y despliegue del sitio web. Ademas de ayudar con los diseños y colores de la pagina.

Las paginas de este proyecto serian: el index que seria la pagina principal, la parte de productos en donde se muestran cada uno con sus precios y detalles. La pagina integrantes incluye los integrantes del trabajo y lo que hizo cada uno y tambien esta la pagina de inicio de sesion la cual es para iniciar sesion y si no puedes te muestra un cartel de "te vas a loguear"
